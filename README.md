# QA Manual Testing Portfolio #

Welcome to my manual testing portfolio. This repository contains structured test suites and test cases for real-world web applications, demonstrating my QA mindset, boundary value analysis, and negative testing approach.

**Projects:**

API Testing (Python) – An automated test that checks if the server communication works correctly. The script can load users, create a new one, verify their details (name, email, address), and safely delete them afterward.

* [IDOS](./idos-testing.md) - Complete test suite covering valid routes, browser cache behavior, and date limits.
  
* [Alza](./alza_cart_testing.md) - Test suite focused on e-commerce logic, shopping cart operations, and input validation for discount codes.

* [Netflix](./netflix_login_testing.md) – Authentication flow testing, validation of multi-input verification codes, and negative security testing.
